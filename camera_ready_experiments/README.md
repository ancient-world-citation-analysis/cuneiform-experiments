# Camera-Ready Experiments

Complete code and outputs for the review-period and camera-ready
experiments of *What Transfers Across Cuneiform?* (EMNLP 2026 Main).
Every number in the camera-ready revision that does not appear in the
original submission is generated by a script in `scripts/` and recorded
verbatim in `outputs/`; `RESULTS.md` is the consolidated ledger.

## Reproducing

Protocol constants live in `scripts/common.py` and match the paper
exactly: 5-fold document-level CV, Morfessor corpusweight 1.0 (except
the Exp K/L sweep), cunei-tools threshold search, document-level paired
bootstrap (2,000 resamples, two-sided), seeds 42–46 where sampling
applies, boundary micro-F1, document filter `len(split) > 2`.

1. Environment: Python 3.11 with pinned `numpy==1.26.4`,
   `pandas==2.2.3`, `scipy==1.13.1`, `morfessor==2.0.6`, and
   `cunei-tools` (the released toolkit). Morfessor's batch training is
   order-stochastic at the ±0.003 level; seed before every training.
2. Data: place the corpus CSVs as described in `data/` (see the
   provenance notes below), then let `scripts/common.py` build its
   cache on first run.
3. Always run `scripts/00_repro_gate.py` first: it verifies your
   pipeline reproduces the published Table 3 before you trust anything
   downstream.

## Data provenance

- **Akkadian**: ORACC exports (RINAP, SAAo); see the repository's
  top-level data documentation.
- **Sumerian**: the paper's SUX corpus is the **394-document ETCSL
  export**, *not* the larger ORACC Sumerian dump — see
  `data/README_SUX_PROVENANCE.md` before attempting reproduction, as
  using the wrong corpus silently changes every Sumerian number.
- **Elamite**: Elamite Lemma Dictionary (CEPOAT) + Utu-našu running
  texts (tracked in the repository's `data/`); the expanded
  871-document Susa corpus of Exp C derives from CEPOAT with the same
  two-pass conversion.
- **Hittite**: `data/7000_hitt_txts_wGloss.csv` (tracked at top level).
- **Old Babylonian (Exp Q)**: the Iltani-archive word sheet with
  BART-model lemma predictions; redistribution pending coauthor
  confirmation — contact the authors for the input file. The script,
  its full protocol, and its outputs are included.

## Integrity note

`outputs/` files are written directly by the scripts (no hand-edited
numbers). Where an experiment's interpretation was superseded during
analysis (Exp J's corpusweight headline, Exp I's transfer artifact),
the ledger records the correction rather than deleting the history.
